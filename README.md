# Dry-Bulb, Wet-Bulb, and Dew-Point Temperatures

An interactive explainer for three temperatures students often confuse. Adjust the dry-bulb temperature and relative humidity and watch the wet-bulb and dew-point temperatures respond.

## Live tool

[Open Dry-Bulb, Wet-Bulb, and Dew-Point Temperatures](https://nuhaaljuneidi.github.io/The-Three-Thermometers/)

## Features

- Side-by-side "thermometer family" showing what each temperature measures and why.
- Live sliders for dry-bulb temperature and relative humidity.
- Shows why DB ≥ WB ≥ DP, and when all three are equal.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
